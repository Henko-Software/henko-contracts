# henko-contracts

Los contratos entre las piezas de Henko, en zod: qué se pide, qué se
responde y qué eventos salen. **Un paquete por módulo**, así cada servicio
depende sólo de los contratos que usa.

| Paquete                                  | Qué define                                                                                                                                                                                                                                                                                                                                              |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `@henko-software/contracts-common`       | piezas que comparten los contratos: `listParam` y `booleanParam` para los filtros de los listados en la query                                                                                                                                                                                                                                           |
| `@henko-software/contracts-identity`     | API interna de `identity` (sesiones con «ver como», usuarios, dispositivos, organización de la instancia, flags guardados), roles, errores y eventos                                                                                                                                                                                                    |
| `@henko-software/contracts-flags`        | catálogo de feature flags (las claves copian la nav), valores guardados y efectivos, y el nodo del panel                                                                                                                                                                                                                                                |
| `@henko-software/contracts-bff`          | API pública de `henko-bff`, la que usa `henko-web` (sesión, flags, Administración armada con contacts, catálogo y precios con catalog, cuenta corriente y plan de cuentas con ledger, padrón de ARCA con fiscal, ventas con sales, compras con purchasing, tesorería con treasury, stock y conteos con stock, producción y trazabilidad con production) |
| `@henko-software/contracts-console`      | feedback que llega de cada instancia, API de la bandeja y trazas de la Henko Console                                                                                                                                                                                                                                                                    |
| `@henko-software/contracts-fiscal`       | API interna de `fiscal` (comprobantes con CAE o CAEA, numeración, puntos de venta, padrón), tablas de códigos de ARCA, errores y eventos                                                                                                                                                                                                                |
| `@henko-software/contracts-contacts`     | API interna de `contacts`: contactos con roles, condiciones de pago, tablas auxiliares, errores y eventos                                                                                                                                                                                                                                               |
| `@henko-software/contracts-catalog`      | API interna de `catalog`: artículos, agrupamientos, listas de precios, precios con vigencia (cadena, aumento masivo, deshacer), bonificaciones por escala, el precio que rige para una venta (`/internal/prices/resolve`), errores y eventos                                                                                                            |
| `@henko-software/contracts-ledger`       | API interna de `ledger`: cuenta corriente de clientes y proveedores (movimientos, imputaciones, saldo, antigüedad, vencimientos, ventas por vendedor), plan de cuentas, comandos y eventos que consume y publica, errores                                                                                                                               |
| `@henko-software/contracts-sales`        | API interna de `sales`: pedidos (autorización, sugerido, último), zonas de reparto, expedición (hojas de ruta, remitos), bandejas, facturas y notas de crédito con su autorización (CAE/CAEA por el orquestador), errores y eventos                                                                                                                     |
| `@henko-software/contracts-treasury`     | API interna de `treasury`: recibos, órdenes de pago, cartera de cheques (depósito, acreditación, endoso, rechazo), cuentas bancarias con saldos, extractos y conciliación, caja proyectada, errores y eventos                                                                                                                                           |
| `@henko-software/contracts-stock`        | API interna de `stock`: ubicaciones, existencias por artículo, ubicación y lote (FEFO), movimientos con contra-movimiento, transferencias, ajustes, conteos, consumo y alta de lotes de producción, errores y eventos                                                                                                                                   |
| `@henko-software/contracts-purchasing`   | API interna de `purchasing`: pedidos a proveedores, recepciones (con lo aceptado y lo devuelto), facturas de compra con lo cobrado de más y su nota de crédito, errores y eventos                                                                                                                                                                       |
| `@henko-software/contracts-production`   | API interna de `production`: plan de producción para una entrega, órdenes (armar, corregir, cerrar con su lote, anular), trazabilidad de lotes hacia atrás y hacia adelante, retiros y simulacros, errores y eventos (lo que mueve el stock viaja en el evento)                                                                                         |
| `@henko-software/contracts-reporting`    | API interna de `reporting`: rubros del estado de resultados (árbol con subtotales por fórmula), a qué rubro va cada fuente (ventas y compras por rubro de artículo), meses y el reporte de un mes, eventos que consume y publica, errores                                                                                                               |
| `@henko-software/contracts-network`      | API interna de `network`: la red de locales con su punto, buscar una dirección y evaluar la esquina (entorno, puntaje abierto, veredicto, franja de venta y alquiler de la zona), lugares guardados con su embudo e historial, errores y eventos                                                                                                        |
| `@henko-software/contracts-people`       | API interna de `people`: empleados (ficha, lugar de trabajo, egreso, contacto de emergencia, papeles con vencimiento y foto, vínculo con un usuario), ausencias con saldo de vacaciones y avisos, la Semana, avisos del Resumen, tablas auxiliares, errores y eventos (sin datos sensibles)                                                             |
| `@henko-software/contracts-orchestrator` | API interna del orquestador (flujos, pasos, intentos, arranque idempotente por `commandId`, cancelación), cabecera de idempotencia de los comandos a módulos, errores y eventos                                                                                                                                                                         |

## Reglas

- **El contrato se cambia acá primero**, y después los servicios.
- **Un cambio que rompe** (sacar un campo, cambiar un tipo) sube el mayor del
  paquete y convive con la versión anterior hasta que nadie la use.
- Los ids son UUIDv7, las fechas ISO en UTC, la plata en centavos.
- Los eventos se nombran `<módulo>.<entidad>.<hecho>.v<n>`.

## Publicar

Subir el `version` del paquete y llegar a `main`.
