# henko-contracts

Schemas zod de las APIs y los eventos de Henko, un paquete por módulo
(`packages/contracts-<módulo>`). Sólo tipos y schemas: nada de lógica,
nada de llamadas HTTP.

Reglas generales en `@henko-software/agent-rules` (las importa el
`CLAUDE.md`). Lo propio: ver el README (versionado y reglas de cambio).
